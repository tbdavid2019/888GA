888GA v0.8.0 is a major feature release introducing the **Clef-Flash System One AI Decision Engine**, native **JetBrains Mono + Gen Jyuu Gothic (源柔黑體)** typography scale without `.woff` dependencies, and a dedicated **`demo` / `demo` Read-Only Demonstration Account** for zero-setup dashboard exploration.

This release represents a major evolution beyond the original upstream architecture, equipping 888GA with autonomous anomaly diagnosis, privacy-first edge AI classification, and enhanced readability for modern developer workflows.

## Highlights

- **Clef-Flash System One AI Decision Engine**:
  - Implemented 3-tier resilient endpoint failover: Primary (`clef.create360.ai`, <200ms, zero external token cost) → Fallback 2 (`clef.aiurl.tw`) → Fallback 3 (`api.typesafe.ai` with Bearer key auth).
  - Integrated fast typed probability scoring (`noul`), discrete multi-class distribution (`choice`), and continuous weighted ratings (`score`).
  - Added **Site Health Diagnosis** evaluating overall score (1–5), primary bottleneck identification (bounce rate, latency, error rate), and traffic authenticity profiling.
  - Added **Incident Anomaly Triage** determining operational urgency (`p0` to `noise`) and suspect cause categories (origin outage, scraper bot surge, tracking snippet failure, off-peak business cycles).
  - Added **Visitor & Bot Defense Classification** evaluating client hints, user agents, paths, and request rates to prescribe edge actions (`allow`, `challenge_turnstile`, `block_or_drop`).
  - Integrated automated AI diagnosis into edge notification pipelines, embedding concise diagnostic insights directly into threshold and change alert emails and webhooks.

- **Refined Typography & Local CJK Font Stack**:
  - Upgraded font stack to **JetBrains Mono** for Latin characters and numbers, paired seamlessly with **Gen Jyuu Gothic (源柔黑體)** for CJK characters.
  - Completely removed webfont `.woff2` downloads and preloads, providing instantaneous local font rendering with zero network latency.
  - Preserved the 13px minimum stroke protection rule for CJK readability across all dashboard cards and sidebars.

- **Dedicated Demo Sandbox Account (`demo` / `demo`)**:
  - Built-in test account with instant access via `demo` / `demo` without requiring initial bootstrap setup or D1 database pre-seeding.
  - Showcases 3 complete demonstration sites (Corporate Website, E-commerce Store, SaaS Platform) with live simulated traffic, geographic distribution, and goal conversion funnels.
  - Enforced strict mutation protection: all write requests (`POST`, `PUT`, `PATCH`, `DELETE`) are safely rejected with `403 Forbidden`, preventing any persistent state modification or data leakage.

## Changes Since v0.7.1

- Added high-resolution dashboard demonstration screenshots in `docs/images/`.
